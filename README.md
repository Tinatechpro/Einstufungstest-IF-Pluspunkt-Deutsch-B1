# Deutsch A2-B1: ÖIF & Cornelsen Test Simulator

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://tinatechpro.github.io/quiz-deutsch-test-a2-b1-oif/)

Interactive, highly functional web application designed for comprehensive practice of the German language at the A2-B1 level. It serves as both a powerful preparation tool for the official Austrian German Language Diploma (ÖIF) and an accurate placement test (Einstufungstest) to determine your current German proficiency.

## 🎯 Project Overview

This practical tool utilizes carefully selected official ÖIF and Cornelsen materials to provide a realistic exam experience. It includes interactive modules for:
- **Grammar Practice (Sprachbausteine):** Extensive multiple-choice exercises focusing on A2-B1 grammar structures.
- **Reading Comprehension (Lesen):** Authentic texts with true/false and gap-fill exercises mirroring the official exam format.
- **Writing (Schreiben):** Prompt models and structured guidelines based on official ÖIF standards.

Whether you are aiming to pass the official ÖIF A2-B1 exam or simply want to assess and improve your German level, this application offers a streamlined and effective learning environment.

## 🚀 Features

- **Real Exam Simulations**: Authentic tasks replicating the exact format of the ÖIF and Cornelsen B1 tests.
- **Instant Feedback**: Real-time validation of answers with visual cues and progress tracking.
- **Responsive Design**: Fully functional and elegantly scaled for both desktop and mobile devices.
- **Dark Mode Support**: Built-in dark theme for comfortable, prolonged reading sessions.
- **High Performance**: Built entirely with Vanilla JavaScript and Modern CSS (Grid/Flexbox) for maximum speed and a zero-dependency architecture.

## 🛠️ Built With

- **HTML5** (Semantic structure)
- **Vanilla CSS3** (CSS Variables, Grid, Flexbox)
- **Vanilla JavaScript** (ES6+, DOM manipulation, state management)
